# ExelCode

Консольный ИИ-чат и coding-агент на Gemini **без API-ключа, cookies и сторонних библиотек**.
Использует анонимный веб-протокол `gemini.google.com`.

```
╭─ ExelCode 1.8.8 ──────────────────────────────────────────────╮
│ чат: Новый чат                              модель: auto→3.5… │
│ папка: ~/project                                      /help │
╰───────────────────────────────────────────────────────────────╯

user › explain HTTP/2 in simple terms, briefly

agent · 3.5 Flash-Lite · 1.8s
        HTTP/2 is a newer version of the protocol used to load web pages.
        • multiplexing, header compression (HPACK), server push
        286 chars · 1.8s · model 3.5 Flash-Lite · /copy
```

## Возможности

- 💬 интерактивный чат со **стримингом** ответа;
- 🧠 **долговременная память** — факты о вас (`/remember`);
- 🗂 **чаты сохраняются** автоматически, можно открывать, переименовывать, удалять;
- 🗜 **сжатие истории**: старая часть диалога пересказывается и живёт в памяти чата;
- 🎛 **выбор модели** (`/model`), с показом фактической модели в подписи;
- 🎭 **роль ассистента** (`/system`) — например, «отвечай как строгий редактор»;
- 🔁 `/retry`, экспорт в markdown, статистика;
- 🤖 **агент**: читает файлы проекта, создаёт и меняет их с diff, бэкапом и откатом; умеет читать фрагменты больших файлов и запускать проверки с авто-исправлением;
- 🛡 **защита от опасных команд**: `rm -rf`, `sudo`, `curl | sh`, `git reset --hard` и подобные блокируются в auto-режиме и явно предупреждаются в `ask`;
- 🧠 **состояние агента в чате**: недавние файлы и последняя задача сохраняются и помогают в «продолжай»;
- ⚡ **умный режим**: сам понимает, когда нужно создать/изменить файл, а когда просто ответить текстом;
- ⚙️ **`/settings`**: все настройки в одном месте, включая таймауты, лимиты и компактный UI;
- 🩺 **`/debug`**: диагностика версии, путей, прокси, git и Gemini-протокола;
- 🔄 **обновления при старте**: на каждом запуске проверяет версию и предлагает обновиться;
- 📱 **компактный UI** для Termux и узких терминалов;
- ⌨️ автодополнение команд по `Tab` и подсказки по `/`;
- 🎨 markdown в терминале: списки, код, заголовки, переносы;
- 🌈 **подсветка синтаксиса** в блоках кода: Python, JS/TS, C/C++/C#/Java, Go,
  Rust, Bash, Ruby, PHP, SQL, JSON, YAML, TOML, HTML/XML, CSS и diff;
- 📦 только стандартная библиотека Python 3.9+;
- 📱 работает в Termux и на обычном Linux.

## Запуск

```bash
cd ExelCode
python3 main.py
```

Или через лаунчер:

```bash
./bin/aifree
```

Один вопрос без REPL:

```bash
python3 main.py -p "объясни, что такое HTTP/2, в двух абзацах"
python3 main.py -p "..." --json
```

### Windows

```bat
cd ExelCode
python main.py
:: или через лаунчер
bin\aifree.cmd
```

- нужен Python 3.9+ из `python.org` или Microsoft Store (необязательно);
- в примерах ниже `python3` заменяйте на `python` — агент подменяет
  `python3` на текущий интерпретатор сам, когда запускает проверки;
- данные лежат в `%LOCALAPPDATA%\ExelCode`, конфиг — в
  `%APPDATA%\ExelCode\config.json` (поддерживаются старые переменные `AIFREE_HOME` / `AIFREE_CONFIG` для обратной совместимости);
- вывод переключается в UTF-8, ANSI-цвета включаются автоматически
  в Windows 10+ (в старом `cmd.exe` без VT цвета отключаются флагом
  `--no-color`);
- автодополнение по `Tab` и история ввода требуют `readline` и работают
  в Linux/Termux; в Windows остальные команды доступны без изменений.

Полезные флаги:

```bash
python3 main.py --new                 # новый чат
python3 main.py --chat 2              # открыть второй чат из списка
python3 main.py --list                # список чатов
python3 main.py --models              # список моделей
python3 main.py -m flash              # выбрать модель
python3 main.py --no-stream           # без стриминга
python3 main.py --ephemeral -p "..."  # не сохранять чат
python3 main.py --check               # проверить связь с Gemini
python3 main.py --debug               # диагностика (можно с --json)
python3 main.py --agent --workspace ~/project --yes -p "создай hello.py"
python3 main.py --agent --workspace ~/project --dry-run -p "..."
python3 main.py --agent --agent-mode plan -p "покажи план"
python3 main.py --agent --undo         # откатить последние изменения агента
python3 main.py --agent --backups      # точки отката
```

## Команды в чате

`/help` показывает команды по группам, сокращения и подсказки, а
`/help <команда>` — подробное описание и примеры (например, `/help agent`).

### Чат

| Команда | Что делает |
|---|---|
| `/new [название]` | создать новый чат и переключиться на него; текущий сохраняется |
| `/chats` | список сохранённых чатов: номер, название, число сообщений, время |
| `/open <номер\|id>` | открыть чат по номеру из `/chats` или по id |
| `/rename <название>` | переименовать текущий чат (без аргумента покажет название) |
| `/delete [номер\|id\|all]` | удалить чат с подтверждением; `all` — удалить все чаты и глобальную память |
| `/reset [all]` | очистить историю текущего чата; `all` — сбросить настройки/чаты/память/кэш/данные |
| `/export [файл]` | сохранить чат в markdown; без аргумента — в папку exports |
| `/retry` | удалить последний ответ и заново отправить последний вопрос |

### Ответ и модель

| Команда | Что делает |
|---|---|
| `/model [имя\|номер]` | выбрать модель: без аргумента — меню, можно `auto`/`flash`/`lite` или номер |
| `/models` | список доступных маршрутов моделей и их описание |
| `/stream on\|off` | включить/выключить печать ответа по мере генерации (сохраняется) |
| `/copy` | скопировать последний ответ в буфер обмена |
| `/system [текст]` | задать роль ассистента; `reset` — сбросить, без аргумента — показать |

### Память

| Команда | Что делает |
|---|---|
| `/memory` | показать факты о вас, которые добавляются в каждый запрос |
| `/memory clear` | очистить всю долговременную память (с подтверждением) |
| `/remember <факт>` | запомнить факт; без аргумента спросит текст |
| `/forget <номер>` | забыть факт по номеру из `/memory` |

### Агент

| Команда | Что делает |
|---|---|
| `/agent [задача]` | без аргумента — меню; с текстом — задача по файлам в папке проекта |
| `/workspace [путь]` | папка проекта агента; `.` — текущая, `reset`/`~` — домашняя |
| `/agentmode [режим]` | `ask` — спрашивать, `auto` — применять сразу, `plan` — только план и diff |
| `/smart on\|off` | сам решает: обычный вопрос — чат, просьба изменить файлы — агент |
| `/agentchat on\|off` | отправлять агенту все обычные сообщения (выключает `/smart`) |
| `/run <команда>` | выполнить команду в папке агента с подтверждением и предупреждениями |
| `/undo` | откатить последние изменения агента из бэкапа |
| `/backups` | список точек отката: время, число файлов, статус, путь |

Подкоманды `/agent`: `menu`, `workspace <путь>`, `mode <режим>`, `undo`,
`backups`, `run <команда>`, `on`/`off` (то же, что `/agentchat`), `smart`.
Задачу можно начать со слова `plan`, `auto` или `ask`, чтобы выбрать режим
только для этого запуска.

### Обновления и диагностика

| Команда | Что делает |
|---|---|
| `/update` | проверить версию на GitHub, установить и перезапустить |
| `/check` | короткий тестовый запрос в Gemini: время ответа и модель |
| `/debug [--no-net]` | версия, Python, платформа, пути, прокси, git, доступность `cfb2h` |
| `/proxy [режим\|команда]` | прокси: `off/auto/always`, список, добавить/удалить свой прокси |
| `/settings [ключ значение]` | все настройки и их изменение (`/settings timeout 90`) |

### Интерфейс

| Команда | Что делает |
|---|---|
| `/stats` | чат, модель, сообщения, пересказ, память, папка и режим агента, пути |
| `/clear` | очистить экран и заново нарисовать баннер (в пайпе — пустая строка) |
| `/compact [auto\|on\|off]` | компактный UI: `auto` в Termux/узких экранах, `on`/`off` вручную |
| `/about` | версия, протокол и папка данных |
| `/help [команда]` | список команд по группам или подробная справка по одной |
| `/quit` | сохранить чат и историю ввода и выйти (`/exit`, `/q`) |

Сокращения: `/h` `/ ?` — справка, `/ls` `/list` — чаты, `/rm` — удалить,
`/title` — переименовать, `/mem` — запомнить, `/cls` — очистить экран,
`/ws` — папка, `/amode` `/mode` — режим, `/do` — агент, `/achat` — чат→агент,
`/dbg` — диагностика, `/config` `/cfg` — настройки, `/version` — о программе.

Дополнительно:

- перенос строки в запросе — `\` в конце строки;
- `Ctrl-C` во время ответа останавливает генерацию и сохраняет часть ответа;
- `Ctrl-C` в приглашении `user ›` (или `agent ›`) — выход;
- `Tab` — автодополнение команд (`/ag` → `/agent`) и аргументов (`/smart o` → `on`, пути, номера чатов).

## Настройки, диагностика и компактный режим

`/settings` показывает все текущие значения. Менять можно точечно:

```text
/settings timeout 90
/settings compact_ui on        # auto | on | off
/settings agent_run_timeout 120
/settings agent_max_diff_lines 80
```

`/debug` собирает сведения для багрепорта: версию, Python, платформу, пути,
прокси, git-ветку/коммит, кэш обновлений и доступность `cfb2h`.
`/debug --no-net` не ходит в сеть, `--debug --json` даёт машинный вывод.

На узких экранах и в Termux включается компактный вывод: баннер без рамки,
короче подписи и diff. Управление — `/settings compact_ui auto|on|off`
или переменная `EXELCODE_COMPACT=1/0`. По умолчанию `auto`; в Termux при
активном компактном режиме под баннером показывается `✓ Termux UI`.

## Прокси

По умолчанию включён режим `auto`: прямое соединение, а при сетевой ошибке
(таймаут, DNS, обрыв соединения) ExelCode автоматически пробует прокси по
очереди и пишет в чат, что подключает прокси (в комплекте 50, если один
не отвечает — берётся следующий).

```text
/proxy auto      # по умолчанию: fallback при сетевой ошибке
/proxy always    # всегда через прокси
/proxy off       # выключить
/proxy list      # список (50 встроенных + свои)
/proxy add 1.2.3.4:8080
/proxy remove 1
```

HTTP-ошибки от Google (403/429/5xx) не считаются «пропал интернет» и не
переключают на прокси. Мёртвые прокси временно пропускаются.

В комплекте есть 50 бесплатных HTTP-прокси; свои добавляются в
`~/.local/share/exelcode/proxies.txt` (Windows: `%LOCALAPPDATA%\ExelCode\proxies.txt`).
Бесплатные прокси ненадёжны и потенциально небезопасны — не используйте
их для чувствительных данных и учитывайте, что это сторонние серверы.

## Подсветка кода

Блоки ``` с языком красятся без Pygments и без интернета:

- ключевые слова — фиолетовым, строки — зелёным, числа — жёлтым;
- комментарии — серым, функции — голубым, встроенные имена — синим;
- JSON/YAML/TOML — ключи и значения, diff — добавления и удаления;
- многострочные строки и комментарии сохраняют цвет между строками;
- неизвестный язык — базовая подсветка строк, чисел и комментариев.

Цвета отключаются флагом `--no-color`, переменной `NO_COLOR` или когда вывод
идёт не в терминал (например, в файл или в пайп).

## Агент

Агент работает прямо внутри приложения — CLI-команды для каждой задачи не нужны.

**Рекомендуемый режим:**

```text
/smart on
```

После этого можно писать обычным языком без `/agent`:
- `создай file.py с print("Hello, World!")` → агент сам создаст файл (автоматически);
- `объясни, что такое HTTP/2` → обычный ответ в чате.

Команды агента:

- `/smart on|off` — умный режим: сам решает, ответить текстом или выполнить действие;
- `/agent [задача]` — меню агента или явная задача по файлам;
- `/agentchat on|off` — отправлять агенту **все** обычные сообщения;
- `/workspace [путь]` — папка проекта (без аргумента — спросит);
- `/agentmode [ask|auto|plan]` — подтверждение: спрашивать / авто / только план;
- `/run <команда>` — запустить команду в папке проекта;
- `/undo`, `/backups` — откат и точки восстановления.

Важно: обычный чат без `/smart`, `/agent` и `/agentchat` **не создаёт файлы на диске** — он только отвечает текстом/кодом.

### Что умеет

- исследует дерево и запрашивает нужные файлы;
- читает **фрагменты больших файлов**: `READ: path.py:1-120`;
- создаёт, точечно правит (`patch`) и удаляет файлы;
- показывает **план и diff** перед записью;
- сохраняет **бэкап** каждого применения и умеет откатывать;
- может запрашивать **проверки** (`run`: тесты, линтер, запуск) и, получив вывод/код возврата, вносить исправления в несколько шагов.

Протокол (формирует модель, вам писать его вручную не нужно):

````
READ: relative/path.py
READ: relative/path.py:10-80
```file path="relative/path.py"
…
```
```patch path="relative/path.py"
<<<<<<< SEARCH
…
=======
…
>>>>>>> REPLACE
```
```delete path="relative/path.py"
```
```run
python3 -m pytest -q
```
````

### Режимы

- `ask` — спрашивать перед записью файлов и запуском команд (по умолчанию);
- `auto` — применять изменения и запускать проверки без вопросов;
- `plan` — только показать план/diff/запрошенные команды, ничего не менять.

CLI-аналоги: `--agent-mode ask|auto|plan`, `--yes`, `--dry-run`.

```bash
# интерактивно (в чате): /agent → меню
python3 main.py

# одной строкой
python3 main.py --agent --workspace ~/project -p "добавь тесты и почини падающие"
python3 main.py --agent --workspace ~/project --agent-mode plan -p "покажи план"
python3 main.py --workspace ~/project --undo
```

Безопасность:

- пути только относительные, внутри `--workspace`;
- запрещены `..`, `~`, `.git`, `.env`, ключи, бинарные файлы;
- `SEARCH` в patch должен совпадать ровно один раз;
- перед записью — подтверждение и резервная копия; команды запускаются с подтверждением;
- опасные команды (`rm -rf`, `sudo`, `curl | sh`, `git reset --hard`, `del /s`,
  `mkfs`, `shutdown` и т.п.) в auto-режиме **блокируются**, а в `ask`
  показываются с явным предупреждением;
- откат: `/undo` или `--undo`, список — `/backups`/`--backups`;
- при не-интерактивном запуске без `--yes` агент работает в режиме плана.

Конфиг (`~/.config/exelcode/config.json`, на Windows — `%APPDATA%\ExelCode\config.json`):

```json
{
  "agent_workspace": "/path/to/project",
  "agent_mode": "auto",
  "agent_chat": false,
  "smart_route": true,
  "agent_context_chars": 30000,
  "agent_max_rounds": 6,
  "agent_max_edit_rounds": 4,
  "agent_max_fix_rounds": 4,
  "agent_run_timeout": 60,
  "agent_run_output_chars": 8000,
  "agent_max_diff_lines": 120,
  "compact_ui": "auto",
  "proxy_mode": "auto"
}
```

## Модели

| id | Что это |
|---|---|
| `auto` | автовыбор Google: может попасться Hydrogen, иначе Flash с веб-доступом |
| `flash` | маршрут Gemini 3.6 Flash |
| `lite` | Gemini 3.5 Flash-Lite |

Без входа в Google анонимные запросы фактически обслуживает **3.5 Flash-Lite**,
поэтому в подписи ответа показывается реальная модель, которую вернул сервер.
Если Google откроет анонимный доступ к другим моделям, достаточно добавить их
hex-id в `aifree/gemini.py` → `MODELS`.

## Память и контекст

- **Краткосрочная память** — последние сообщения чата; они попадают в промпт.
- **Долговременная память** — список фактов в `memory.json`, добавляется в каждый запрос.
- **Пересказ** — когда в чате накапливается больше 16 сообщений, старая часть
  сжимается Gemini в 5–10 пунктов и заменяет её в контексте. Сами сообщения
  остаются в файле чата и в экспорте.

Промпт собирается как один запрос: `<system>`, `<memory>`, `<summary>`,
`<dialogue>`, `<user>`. Это надёжно работает с анонимным веб-протоколом, который
не хранит серверную сессию.

## Где лежат данные

```
~/.local/share/exelcode/
├── chats/<id>.json      # chats
├── memory.json          # long-term memory
├── exports/             # markdown exports
├── backups/             # agent backups
├── update_check.json    # кэш проверки обновлений
└── history              # readline history

~/.config/exelcode/config.json   # model, stream, last chat
```

Override with `EXELCODE_HOME` / `EXELCODE_CONFIG` (legacy `AIFREE_HOME` / `AIFREE_CONFIG` also supported).
On Windows by default: `%LOCALAPPDATA%\ExelCode\` for data and `%APPDATA%\ExelCode\config.json` for config.

## Как это работает

1. `GET https://gemini.google.com/app` — берём номер сборки `cfb2h`.
2. `POST .../BardChatUi/data/.../StreamGenerate` с form-полем `f.req`
   (массив из 99 слотов, модель задаётся заголовком `x-goog-ext-525001261-jspb`).
3. Читаем поток `wrb.fr` построчно; кадры содержат накопительный текст,
   поэтому приложение печатает только приращение.
4. Если запрос не удался — один повтор на запасной модели и свежий `cfb2h`.

## Ограничения

- Это **неофициальный** веб-протокол. Google может изменить его в любой момент,
  включить капчу или ограничить частоту запросов.
- Анонимный режим обычно отдаёт только **3.5 Flash-Lite**.
- Бесплатный режим Google может использовать запросы для улучшения продуктов.
  **Не отправляйте пароли, ключи и чужие персональные данные.**
- Нет вложений, картинок и инструментов — только текст.
- Один запрос = один ответ; серверная история не используется, контекст
  собирается локально.
- Агент меняет файлы и запускает команды только после подтверждения (кроме режима `auto`) и только внутри `--workspace`; не подтверждайте опасные команды и не запускайте агента на папках без бэкапа или git.

## Если что-то сломалось

- `Google отклонил анонимный запрос (403)` — подождите несколько минут.
- `429` — слишком часто; сделайте паузу.
- `Gemini: на странице нет cfb2h` — Google поменял страницу; проверьте
  `PAGE_URL`/`RPC_URL` в `aifree/gemini.py`.
- Ответов нет вообще — проверьте сеть: `curl -I https://gemini.google.com/app`.
