# ПРОГРЕСС — ExelCode

**Дата:** 2026-11-21  
**Версия:** 1.8.16  
**Репозиторий:** https://github.com/Exelka/ExelCode (public)

Консольное приложение на Python (только стандартная библиотека): AI-чат и coding-агент, работающий через анонимный веб-протокол Gemini (`gemini.google.com`) без API-ключа и cookies.

---

## Что было сделано

### 1. Keyless-доступ к Gemini (основа)
- Исследован и восстановлен анонимный веб-протокол:
  - `GET https://gemini.google.com/app` → извлечение `cfb2h` (build id).
  - `POST /_/BardChatUi/data/assistant.lamda.BardFrontendService/StreamGenerate` с `f.req`, нужными заголовками/расширениями.
  - Парсинг потоковых кадров `wrb.fr`, сбор накопительного текста, очистка служебных артефактов.
- Подтверждено: анонимно фактически отвечает **Gemini 3.5 Flash-Lite** (маршруты других моделей присутствуют, но доступны по факту не всегда).
- Исправлен `weather.py` (замена неработающего DuckDuckGo chat на рабочий Gemini bypass), проверено в Ubuntu/proot и Termux.

### 2. Приложение `ai-free` (чат)
- Структура: `main.py`, `aifree/{cli,ui,gemini,config,store,prompt,render,highlight,agent}.py`, `README.md`, лаунчер `bin/aifree`, тесты.
- Чат:
  - Стриминг ответа с дельтами, обработка ошибок/повторов, остановка по Ctrl-C.
  - Персистентные чаты (`~/.local/share/ai-free/chats/*.json`), авто-название, `/new /chats /open /rename /delete /retry /export /reset /stats`.
  - Долговременная память фактов (`memory.json`), `/memory /remember /forget`.
  - Системная роль/инструкции (`/system`), сборка промпта с `<system>/<memory>/<summary>/<dialogue>`.
  - Авто-сжатие старой истории в summary при росте контекста.
  - Выбор модели (`/model`, `--model`), отображение фактической модели ответа.
  - CLI: `-p/--prompt`, `--new/--chat/--list/--models/--check/--json/--no-stream/--ephemeral` и др.
- Рендеринг:
  - Markdown в терминале: заголовки, списки, цитаты, код-блоки, переносы.
  - Подсветка синтаксиса в code-блоках (Python, JS/TS, C/C++/C#/Java, Go, Rust, Bash, Ruby, PHP, SQL, JSON/YAML/TOML, HTML/CSS, diff), состояние многострочных строк/комментариев, отключение при `--no-color`/не-TTY.
- Хранение: данные в `~/.local/share/ai-free`, конфиг в `~/.config/ai-free/config.json`, атомарная запись.

### 3. Coding-агент
- Текстовый протокол (без нативного tool-calling у анонимного Gemini): `READ` (в т.ч. диапазоны строк), блоки `file`/`patch`/`delete`, `run`.
- Возможности:
  - Исследование workspace, чтение файлов и фрагментов больших файлов.
  - Создание/перезапись, точечные патчи (уникальный SEARCH/REPLACE), удаление.
  - План и diff перед применением, подтверждение, режимы `ask / auto / plan (dry-run)`.
  - Бэкапы каждого применения и откат (`/undo`, `/backups`, `--undo/--backups`).
  - Запуск команд/проверок с подтверждением, возврат вывода/кода и цикл «исправить → проверить».
  - Безопасность: sandbox внутри workspace, запрет `..`/абсолютных путей/symlink-выхода, запрет служебных и секретных файлов (`.git`, `.env`, ключи и т.п.), игнор кэшей/бинарников, лимиты размера.
- UX агента в приложении: `/agent` (меню/задача), `/workspace`, `/agentmode`, `/run`, `/undo`, `/backups`, CLI-флаги `--agent/--workspace/--agent-mode/--yes/--dry-run/--undo/--backups`.

### 4. Умный режим и удобство ввода
- `/smart on` — авто-маршрутизация: просьбы создать/изменить/запустить воспринимаются как задачи агенту (авто), обычные вопросы — как чат (без лишнего сканирования файлов).
- `/agentchat on|off` — направлять все обычные сообщения агенту.
- Быстрый ответ без сканирования для разговорных/общих вопросов при работе через агентный ввод.
- Автодополнение по **Tab**: команды (`/`), подкоманды/режимы, номера/ID чатов, пути.

### 6. Windows-совместимость (1.3.1)
- `aifree/console.py`: принудительный UTF-8 для stdin/stdout/stderr и включение
  ANSI (`ENABLE_VIRTUAL_TERMINAL_PROCESSING`) — без этого любой русский `print`
  падал с `UnicodeEncodeError` на cp1251/cp866, а `/clear` и стриминг печатали
  escape-коды текстом.
- Пути по платформе: данные в `%LOCALAPPDATA%\ai-free`, конфиг в
  `%APPDATA%\ai-free\config.json` (переменные `AIFREE_HOME`/`AIFREE_CONFIG`
  по-прежнему главнее).
- Агент: файлы читаются с нормализацией CRLF→LF (иначе SEARCH из ответа модели
  не совпадал с файлом), при записи исходный перевод строки сохраняется,
  `atomic_write` пишет байты без автозамены `\n`→`\r\n`.
- `execute_command`: `python3 ...` на Windows подменяется на текущий
  интерпретатор (имя `python3` там обычно отсутствует или является заглушкой
  Microsoft Store с кодом 9009).
- Лаунчер `bin/aifree.cmd`; README дополнен разделом про Windows.
- Тесты без сети: **36** (добавлены проверки нормализации CRLF, сохранения
  CRLF при патче и адаптации команд).

## Текущее состояние и ограничения

- Зависит от **неофициального веб-протокола** Gemini: Google может изменить его, включить капчу/лимиты; при сбоях возможны ошибки 403/429/пустые ответы.
- Анонимный доступ фактически даёт в основном **3.5 Flash-Lite**; качество сложных coding-задач ограничено моделью.
- Нет нативного tool-calling: агент работает через текстовый протокол и эвристики, модель может ошибаться в формате — есть валидация, feedback и откат, но надёжность не абсолютная.
- Эвристика «вопрос vs действие» не идеальна; в спорных случаях можно явно вызвать `/agent <задача>`.
- Авто-режим меняет файлы/запускает команды без подтверждения (с бэкапом) — использовать в нужной папке проекта, желательно под git.
- Нет вложений (файлы/изображения в чат), нет встроенного веб-поиска/браузера; только локальные текстовые файлы workspace в рамках ограничений.
